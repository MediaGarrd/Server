# Contributing to the MediaGarrd Server

## Submitting Issues
Open an issue [here](https://github.com/MediaGarrd/Server/issues) using the template that best fits the issue.

The `Status: Needs Triage` label will automatically be applied. Once this issue has been reviewed/approved, the `Status: Approved` label will be added and Pull Requests can be opened referencing this issue.

## Pull Requests
Pull requests should only be opened for issues that have the `Status: Approved` label.

## AI Usage
See [AGENTS.md](https://github.com/MediaGarrd/Server/blob/main/AGENTS.md) for a more in-depth overview of the way AI is permitted in code submissions. If a signature is not present on a commit that even *appears* to be generated by an LLM, the PR will be closed. This is strictly for the continued maintainability of the project.
